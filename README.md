# 🛋️ Maracaibo Furniture – E-Commerce Website

Maracaibo Furniture is a responsive front-end e-commerce website for showcasing and selling furniture products such as sofas, beds, chairs, tables, storage units, and accessories.

The project focuses on clean UI design, correct asset handling, and cart functionality using **HTML, CSS, and JavaScript**, with preparation for future backend integration using **Laravel API**.

---

## 🚀 Features

- 🏠 Home page with category navigation  
- 🛋️ Product pages (Sofas, Beds, Chairs, Tables, Accessories)
- 🖼️ Dynamic product loading using JavaScript
- 🔍 Image zoom (modal view)
- 🛒 Add to Cart functionality
- 💾 Cart stored in `localStorage`
- ➕ Quantity handling
- ❌ Remove items from cart
- 💰 Total price calculation
- 📱 Responsive design

---

## 🛠️ Technologies Used

- **HTML5**
- **CSS3**
- **Vanilla JavaScript**
- **Font Awesome**
- **LocalStorage**
- **Laravel (backend – future integration)**
